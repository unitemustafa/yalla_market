# Yalla Market 1.0.38 (12071)

- Add shared button press feedback, staggered list entrances, and a theme reveal
  that keeps the current page, form drafts, and navigation state.
- Animate catalog cards into product and store pages on Android. Keep native
  Cupertino routes and interactive edge-swipe back navigation on iOS, in both
  Arabic and English.
- Keep the product title and cart pinned while the image gallery collapses.
  Show cart feedback only after the item is saved; prevent duplicate submissions.
- Bound startup waits and offer an explicit retry when startup cannot finish.
  Optional preference reads and location suggestion history do not block startup.
- Preserve the Android application ID, signing identity, and storage keys for an
  in-place update from existing releases.

## Verification

- Full Flutter suite, static analysis, formatting, translation consistency,
  source-size check, and Android production preflight.
- iOS widget tests cover edge-swipe navigation, independent nested card actions,
  and safe placement of product controls in portrait and landscape with display
  cutouts, larger text, and both reading directions.
- The new UI dependencies are Dart/Flutter packages: `animations` supplies the
  Material container transition; `animated_theme_switcher` supplies the theme
  reveal. Existing Cubit and domain/data boundaries remain in place.

Widget tests do not establish native iOS release readiness. A signed physical
iPhone build still needs an Apple Development Team, provisioning, and validation
on macOS/Xcode; the local iOS preflight currently reports the missing team.
